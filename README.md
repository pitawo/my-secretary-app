# Secretary — 自分専用の秘書アプリ

メモ・タスク・週次の振り返りを1画面で管理する Node.js アプリ。
**npm install 不要**（Node.js の標準モジュールだけで動く）。

## 使い方

1. このフォルダでターミナルを開く
2. 起動する

   ```
   node server.js
   ```

   （`npm start` でも同じ）

3. ブラウザで <http://localhost:3000> を開く
4. 終了は ターミナルで `Ctrl + C`

## 機能

### ダッシュボード（画面上部）
- メモの件数 / タスクの件数 / 完了タスク件数 / 振り返りの件数
- **最新の振り返り**（一番新しい週のコメントをそのまま表示）

### メモ
- タイトルと本文を入力して追加
- 一覧表示（新しい順）／作成日時を表示
- **編集**（カード内にフォームが開く。保存すると「編集済み ○/○ ○:○」が付く）
- 削除

### タスク
- タスクを入力して追加
- 一覧表示（新しい順）／作成日時・完了状態・完了日時を表示
- 「完了」で完了済みに（「戻す」で未完了に戻る）
- **編集**（内容の書き換え。完了状態は保持）
- 削除

### 週次の振り返り
- 対象の週を選んでコメントを記録（初期値は今週）
- **同じ週にもう一度記録すると上書き**（1週1件）
- 一覧表示（新しい週が上）／「2026年 第32週（8/3〜8/9）」の形式で表示
- 編集・削除

## データの保存先

`data/data.json` に自動保存される。アプリを閉じても消えない。
中身はただの JSON なので、テキストエディタで開けば確認できる。

```
App/
├── server.js        … サーバー本体（APIとファイル保存）
├── package.json
├── data/
│   └── data.json    … 保存データ（初回起動後に自動生成）
└── public/          … 画面側
    ├── index.html
    ├── style.css
    └── app.js
```

## API 一覧（動作確認用）

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/data` | メモ・タスク・振り返りを全部取得 |
| POST | `/api/memos` | メモ追加 `{ "title": "...", "content": "..." }` |
| PATCH | `/api/memos/:id` | メモ編集 |
| DELETE | `/api/memos/:id` | メモ削除 |
| POST | `/api/tasks` | タスク追加 `{ "title": "..." }` |
| PATCH | `/api/tasks/:id` | タスク編集 |
| PATCH | `/api/tasks/:id/toggle` | 完了 / 未完了を切り替え |
| DELETE | `/api/tasks/:id` | タスク削除 |
| POST | `/api/reviews` | 振り返りを記録 `{ "week": "2026-W32", "comment": "..." }`（同じ週は上書き） |
| PATCH | `/api/reviews/:id` | 振り返り編集 |
| DELETE | `/api/reviews/:id` | 振り返り削除 |

## 実装メモ（つまずいた点・工夫した点）

- **同時に書き込むとデータが消えるバグを修正した。**
  各リクエストが「ファイルを読む→書き換える→保存する」をしているので、
  処理が重なると後から保存したほうで上書きされ、追加したデータが消えていた
  （10件を同時に追加したら2件しか残らなかった）。
  `server.js` の `serialize()` で API の処理を1件ずつ順番に流すようにして解決。
- 保存は一時ファイル `data.json.tmp` に書いてから rename する。書き込み途中で落ちてもファイルが壊れにくい。
- 週は ISO 週番号（`2026-W32`、月曜はじまり）で持つ。文字列のまま並べ替えれば新しい週が先頭に来る。
- 画面はライト / ダークの両方に対応（OSの設定に自動追従）。

## メモ（困ったとき）

- ポート 3000 が別のアプリで使われていると起動に失敗する（`EADDRINUSE`）。その場合は `server.js` の `PORT` を `3001` などに変更する
- 保存データを全部消したいときは `data/data.json` を削除して再起動する
- `<input type="week">` に対応していないブラウザでは、`2026-W32` の形式で直接入力すれば動く
